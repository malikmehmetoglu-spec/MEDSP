# مخطط قاعدة البيانات

ملفات الترحيل هنا هي المرجع الكامل لقاعدة بيانات نظام المشاريع والاستبيانات،
مطابقة لما هو مطبّق على Supabase. تُنفَّذ بالترتيب على أي PostgreSQL 15+.

## النقل إلى الخادم الداخلي

الملفات تعتمد على ثلاثة أشياء خاصة بـ Supabase يجب توفيرها على الخادم:

- مخطط `auth` وجدول `auth.users` ودالة `auth.uid()` — توفّرها GoTrue
  (خادم المصادقة مفتوح المصدر من Supabase) أو بديل يضبط نفس الدالة.
- الأدوار `anon` و `authenticated` — توفّرها PostgREST.
- امتداد `pgcrypto` في مخطط `extensions`.

أبسط طريق: تشغيل Supabase مستضافاً ذاتياً (docker) على الخادم الداخلي،
ثم تنفيذ هذه الملفات، وتغيير `VITE_SUPABASE_URL` و `VITE_SUPABASE_KEY`.

## نموذج الأمان

- كل الجداول مغلقة بـ RLS. لا توجد أي سياسة لدور `anon`.
- الزائر يصل فقط عبر أربع دوال: `get_public_survey`، `unlock_survey`،
  `submit_response`، `list_published`.
- كلمات مرور الاستبيانات بصمات bcrypt، والتحقق على الخادم.
  عمود البصمة لا يُقرأ حتى للمسجّلين (صلاحيات أعمدة).
- المشرف = حساب موجود في جدول `admins`. إنشاء حساب لا يمنح أي صلاحية.

## إضافة مشرف

بعد أن ينشئ الشخص حسابه من شاشة الدخول:

```sql
insert into public.admins (user_id, display_name)
select id, 'الاسم' from auth.users where email = 'البريد@example.com';
```
